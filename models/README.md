# Model checkpoints

This directory is ignored by Git. The default commands look for:

- `models/logo_detector.pth`
- `models/brand_recognizer.pt`

Release checkpoints through a versioned archive, Hugging Face, Zenodo, or another durable host, then put the public download URL and SHA-256 checksum in `docs/DATA_AND_MODELS.md`. Do not commit multi-hundred-megabyte or gigabyte checkpoints directly to GitHub.
